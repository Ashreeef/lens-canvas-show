# Lens Canvas Show

Driver Monitoring System presentation app for the ENSIA x Qareeb 2025-2026 group project.

## Stack

- React + TypeScript + Vite
- Tailwind CSS + shadcn/ui
- Vitest for unit tests
- Playwright for end-to-end tests

## Scripts

- `npm run dev` starts the development server
- `npm run build` creates a production build
- `npm run preview` previews the production build
- `npm run test` runs unit tests once
- `npm run test:watch` runs unit tests in watch mode

## Project Notes

- Slide content lives in `src/pages/Index.tsx`.
- Presentation styling lives in `src/styles/presentation.css`.
